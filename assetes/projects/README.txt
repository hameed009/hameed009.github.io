Add project images here.

For each project folder (e.g. nexus/):
  cover.jpg  = card image (recommended 1600x1000)
  shot1.jpg, shot2.jpg, shot3.jpg, shot4.jpg = preview gallery screenshots (recommended 1600x900)

Missing images are skipped automatically. To show more than 4 screenshots, raise "shots" for that project in projects.js.
Links: fill "github" and "live" in projects.js; empty links are hidden.
